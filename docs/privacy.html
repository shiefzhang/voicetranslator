一句话概括：这个应用不收集你的任何数据。

它没有账号、不联网、不包含任何统计或广告 SDK。语音识别与翻译全部在本机完成， 开发者无法获取你使用本应用的任何信息。

一我们不收集任何数据

本应用没有账号体系，不与任何服务器通信，不包含广告、分析或任何第三方统计 SDK。 应用内不存在任何形式的用户行为上报。

因此，我们也无法向任何第三方提供、出售或共享你的个人信息—— 因为我们从未获得这些信息。

二录音如何处理

语音识别（ASR）与机器翻译（NMT）全部在你的设备本地完成，模型文件随应用一同分发。

  • 录音数据仅存在于内存中，用于当次识别；
  • 处理完毕后即被丢弃，不会写入磁盘；
  • 不会离开你的设备，不存在任何上传行为。

在飞行模式下，本应用的全部功能均可正常使用，这一点可以自行验证。

三麦克风权限

本应用仅在你主动点击录音按钮时请求麦克风权限，不会在后台录音。

你可以随时在系统的「设置 → 隐私与安全性 → 麦克风」中撤销授权。 撤销后仅录音相关功能不可用，其余功能不受影响。

四模型包

你可以自行导入扩展翻译模型文件（.vtmodel）。这些文件仅保存在本应用的 沙盒目录中，不会被上传到任何地方；你也可以随时在设置页中移除它们以回收存储空间。

五儿童隐私

本应用不收集任何数据，因此不涉及儿童个人信息（包括《儿童在线隐私保护法》COPPA 及《通用数据保护条例》GDPR 所定义的范畴）的收集与处理。

六政策变更

如本政策发生变更，我们会在应用更新的版本说明中告知。继续使用即表示接受更新后的政策。

Privacy Policy

VoiceTranslator — Offline Speech Translation

Effective: October 12, 2026

In one sentence: this app collects no data about you. There is no account, no network access, and no analytics or advertising SDK. Speech recognition and translation run entirely on your device.

1. We collect nothing

The app has no accounts and never contacts any server. It contains no advertising, analytics, or third-party tracking SDK of any kind.

2. How recordings are handled

Speech recognition and translation happen on-device using models shipped with the app. Audio exists in memory only for the duration of a single utterance, is discarded immediately afterwards, is never written to disk, and never leaves your device. All features work in Airplane Mode.

3. Microphone permission

The app requests microphone access only when you tap the record button. It never records in the background. You may revoke access at any time in Settings → Privacy & Security → Microphone; only recording stops working.

4. Model packages

You may import optional translation model files (.vtmodel). They are stored only inside the app sandbox, are never uploaded, and can be removed at any time from Settings.

5. Children's privacy

Because the app collects no data at all, it does not collect personal information from children as defined by COPPA or GDPR.

6. Changes

If this policy changes, we will note it in the app's release notes.
